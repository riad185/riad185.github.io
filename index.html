FAQ

Common questions.

Is this script detected?
Every MM2 script carries detection risk. This hub uses client-side visual features (ESP, chams, Fullbright) that are safest, and gates riskier features (Silent Aim, Kill All, pre-round fling) behind toggles you control. Use an alt account for testing.
Do I need a key?
No. Completely keyless. No linkvertise, no Discord joins, no captcha. Paste the loadstring and it runs.
Will it work on mobile?
WindUI supports mobile out of the box. Some features (fly with WASD, keybinds) are tuned for desktop, but ESP, coin farm, and most auto-features work on mobile executors.
How do I save my settings?
Automatic. Every toggle, slider, and saved coordinate writes to RiadHub/config.json in your executor's workspace folder. Manual save/reload buttons are in the Misc tab.
Can I see the source code?
Yes. Full source on GitHub at github.com/riad185. Read it, fork it, suggest changes.
A feature stopped working after a game update. What now?
MM2 patches remote names periodically. When that happens, affected features go quiet until the script is updated. Open an issue on GitHub and it'll get patched.
