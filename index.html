FAQ

Everything before you ask.

How do I run the hub?▼

Paste the loadstring from the GitHub repo's README into your executor while you're in Murder Mystery 2. RightControl opens and minimizes the menu; the toggle key can be rebound in Settings.

Which UI is it built on?▼

Linoria Lib — the same UI family used by well-known hubs. It gives tabs, groupboxes, key pickers per feature, theme manager and per-user config saving out of the box, and every element is wired to its own module file.

Am I getting detected?▼

The hub itself is plain Roblox scripting in a public repo — nothing here edits memory. Staying safe is about your executor more than the script. Do not run anything case features require, and read the FAQ before you enable role ESP or silent aim in a full lobby.

Does farming work while I'm off the keyboard?▼

Yes — auto farm handles respawn on a full bag, steers around the murderer, and can auto-fling whoever spawned near you after you respawn. Anti AFK keeps the session from being kicked while the farm loop runs.

Is the hub open source?▼

Fully — the repo is public. Every module lives in the modules/ folder and loads its own logic; if you want to contribute a fix or a new lighting preset, open a pull request and you'll be named in the tab's hourly handles and release notes.

Will it survive an MM2 update?▼

The UI is update-proof and loads live each run. Modules that touch game internals get patched here as fast as the source repos publish their fix — rejoin with the hub once the update notification posts.
