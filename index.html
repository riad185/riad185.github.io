FAQ

Common questions.

Is this script detected?
Every MM2 script carries detection risk — the game uses Roblox's standard replication model. This hub leans on client-side visual features (ESP, cham, Fullbright) that are the safest, and gates the riskier features (Silent Aim, Kill All) behind toggles you control. Use an alt account for testing.
Do I need a key?
No. Completely keyless. No linkvertise, no Discord joins, no captcha. Paste the loadstring and it runs. This was the whole point of building it.
Will it work on mobile?
Yes. WindUI supports mobile out of the box — the floating toggle button and responsive layout handle touch. Some desktop-centric features (fly with WASD) won't map cleanly to mobile, but ESP, coin farm, and auto-features all work.
How do I save my settings?
It's automatic. Every toggle, slider, and saved coordinate writes to ENI_MM2/config.json inside your executor's workspace folder. Use the Misc tab buttons to manually save, reload, or reset.
Can I see the source code?
Yes. The full source lives on GitHub at github.com/riad185/ENI-mm2-Hub. Read it, fork it, suggest changes. It's yours too.
A feature stopped working after a game update. What now?
MM2 periodically patches remote names. When that happens, the affected feature goes quiet until the script is updated. Open an issue on GitHub or ping in the usual place — patches usually land within a day.
