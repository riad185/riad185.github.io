FAQ

Questions.

Is it detected?
Every Roblox script carries detection risk. Client-side visuals like ESP, chams, and fullbright are safest. Riskier features (silent aim, kill all, pre-round fling) are gated behind toggles you control. Use an alt account for testing.
Do I need a key?
No. Completely keyless. No linkvertise, no Discord joins, no captcha. Paste the loadstring and it runs.
Will it work on mobile?
Yes. Mobile buttons and touch support are enabled in the window. Some desktop-tuned features (fly with WASD, keybinds) map differently, but ESP, coin farm, and most auto-features work fine.
How do I save my settings?
Automatic. Every toggle and slider writes to RiadHub/config.json in your executor's workspace. Manual save, reload, and reset buttons are in the Misc tab.
How do I change the theme?
Open the Settings tab inside the hub and pick a theme from the gallery. The effects and watermark can also be configured there.
Where's the source code?
Public on GitHub at github.com/riad185/Riad-mm2-Hub. Read it, fork it, suggest changes.
A feature stopped working after an update.
MM2 patches remote names periodically. When that happens, affected features go quiet until the script updates. Open an issue on GitHub and it gets patched.
