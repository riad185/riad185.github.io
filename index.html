▲ Nocturne — what it is

The external overlay client behind the hub's server tools: pure ReadProcessMemory, no driver, no injection. Full tc-style UI, working themes, live lighting (skybox / fog / exposure / clock), ESP, aim and movement engines ported with per-frame read caching so the game doesn't feel it.

▲ What it does in-game

ESP flags with tc's state table, corner boxes, health bars, target warning icons, aimbot + silent aim threads, speed and fly with write guards, noclip, orbit, hit tracers, hitsound, menu streams a working console. F8 exits clean.

▲ Why it exists

The hub is in-game scripting. Nocturne is the outer layer: overlay rendering, camera math, engine telemetry — visible to nobody, hiding nothing in-process. Both are open source on the profile and both update from the same channel.

LIVE STRIPS // FAQ

Everything before you ask.

How do I run the hub?▼

Open your executor inside Murder Mystery 2, paste the loadstring above, execute. The menu opens itself; RightControl minimizes and restores it, and the toggle key is rebindable in Settings → Menu.

Which UI is it built on?▼

Linoria Lib — tabs, groupboxes, per-feature key pickers, a theme manager with built-in presets, and per-user config saving. Every control is wired to its own module file under modules/, so features ship independently of the UI.

Am I getting detected?▼

The hub is plain client-side scripting in a public repo — nothing edits memory. Safety depends more on your executor than on the script. Nocturne is external too: it reads memory out-of-process and never injects.

Does auto farm work while I'm off the keyboard?▼

Yes — it handles respawn when the bag fills, steers around the murderer, and can auto-fling whoever spawned near you after respawn. Pair it with anti AFK in Server tools and it runs the whole round.

Is everything open source?▼

Fully. The hub and Nocturne both live on github.com/riad185. Pull requests are welcome — a new lighting preset or a movement mode is a single module file.

Will it survive an update?▼

The UI loads live on every run, so menus survive almost anything. Modules that touch game internals get patched as fast as their sources publish; the hub pulls fresh modules each execute.
